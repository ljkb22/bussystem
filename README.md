## 二．主要操作说明

### 1.主页选择管理或者访客

两个不同选项后有不同的功能，管理部分为对路线的管理操作，访客部分为查询公司和换乘查询

### 2.管理：添加路线

这是管理部分的所有功能

这是添加路线的页面，可以把路线的所有信息登记并输入到数据库中

若信息填写无误，转到上面的页面，并自动跳转到主页

若填写站点有误，报错

### 3.管理：修改路线

这是修该路线的初始界面

要输入正确的路线名称

否则会报错

输入正确路线名后，可进行修改

### 4管理：删除路线

这是删除路线的初始界面

输入存在的路线名，方能正确操作，否则网页会报错

### 5.管理：搜索路线

搜索类型中精确指完整的路线名，模糊是指包含搜索值的所有路线

返回的结果按排序方式指定的方式排列

### 访客：出行

这是访客界面的两个功能显示

点击出行后的界面

用松江两个校区举例

### 访客：公司查询

只有编纂的一些公司名

这是查询结果，只包括随便编的Phone和City
